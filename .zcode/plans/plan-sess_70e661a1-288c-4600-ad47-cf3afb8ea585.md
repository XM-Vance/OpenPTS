## 关键技术处理

1. **API Key 品牌化**：`ptis_` 前缀 → `openpts_`（apikey.go 的 GenerateAPIKey）
2. **bonds 删除适配**：OpenPTS 有 `0040_bonds` + `0102_bonds_org` 迁移 + bonds 页 + bonds.ts + menu 种子。新迁移 DROP TABLE + DELETE menu_pages + 前端删页/api client
3. **OTel 拆分**：取 backend observability + main + compose + tempo，剥离 algo-service tracing
4. **3f4c9bd 拆分**：取通用（elevate_guard/util/handler 隔离），剥离 algo/match.go + settlement/anhui.go + 省份复盘
5. **契约产物**：openapi.yaml 手工补 `/auth/api-keys` + `/auth/api-key/exchange` 路径；types.gen.ts 重生成；无 routes.golden
6. **docling 保留**：不动 docling-service，compose/env 保持现状
7. **钉钉彻底不碰**：不引入 dingtalk 包、不加迁移、不加 .env 占位、main.go 不加 dingtalk 初始化
